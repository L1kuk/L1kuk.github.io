# Personal homepage

Website: https://l1kuk.github.io/

## 填写个人信息

在 GitHub 中打开 `index.html`，点击铅笔编辑，并替换以下占位符：

- `[Your Full Name]`：网页标题中的真实姓名拼音。
- `[Your Full Name in Pinyin]`：页面显示的真实姓名拼音。
- `[Your Academic Role / Student Status]`：真实学术身份，例如本科生、硕士生或博士生；不要保留不符合本人情况的身份。
- `[Your Department / School]`：院系英文名称。
- `[Your University]`：学校英文名称。
- `[Your OpenReview Institutional Email]`：注册 OpenReview 使用的校园邮箱。

填写完成后，删除页面底部的 `under construction` 提示段落，以及 head 中的 `robots` meta 标签。提交修改，等待 GitHub Pages 自动发布。

先在无需登录的浏览器窗口中确认主页能显示真实信息，再将主页网址填写到 OpenReview。占位符本身不能用于身份核验，填写完整也不保证审核自动通过。

这是独立的公开主页仓库，不需要公开任何实验代码或私有仓库。请勿在此仓库提交密码、访问令牌或邮件中的激活链接。

## 发布设置

Settings → Pages → Deploy from a branch → 默认分支 → /(root)。
网站直接使用 `index.html`，不需要额外创建 `index.md`，也不需要安装依赖。
